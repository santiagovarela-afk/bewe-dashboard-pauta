## Acciones para Santiago / equipo

### 1. Conectar el token Meta (cuando lo tengan)

Edita `dashboard-meta/.env.local`:

```bash
META_TOKEN=EAA...el-token-completo
```

Reinicia `npm run dev`. Pulsa **Actualizar** en el dashboard. Datos en vivo.

Instrucciones detalladas en README sección "Para tu equipo · onboarding del token Meta".

### 2. Verificar onboarding flows

Cierra sesión → entra → visita Anuncios / Orgánico / Parrilla. Cada uno muestra un tooltip de 3-4 pasos la primera vez. Storage keys: `bw_onb_anuncios`, `bw_onb_organico`, `bw_onb_parrilla`. Para resetear: `localStorage.clear()`.

### 3. Probar el AI dock

- Click en el FAB violeta-cyan abajo a la derecha → abre chat
- `Ctrl+K` (o `Cmd+K`) abre/cierra desde cualquier tab
- Chips contextuales cambian según la tab activa
- Click en "Preguntar al AI" en Campañas → auto-abre y envía pregunta sobre esa campaña

### 4. Decidir despliegue

Cuando quieran publicar:
1. `npm install -g vercel`
2. `vercel link`
3. Agregar env vars en Vercel: `META_TOKEN`, `GEMINI_API_KEY`
4. `vercel --prod`
